Why loxx

Built for the command you only half remember

Find it by what it did

Ran docker system prune -af months ago? Search “free up disk space” and it comes up, though the two share no words.

Get commands you never ran

About 29,000 examples from tldr pages, shown only for programs installed on your computer and marked suggested.

Passwords never reach the disk

API keys, tokens and passwords become <REDACTED> before anything is saved. Start a command with a space to skip it entirely.

Your terminal stays fast

How it works

Three steps, then you forget it is there

  1. 1

    Install with one line

    No sudo. The installer checks the download, then imports your existing bash and zsh history, so you can search it right away.

  2. 2

    Keep working

    Every command is saved with its folder, exit code and how long it took. Secrets are removed before saving.

  3. 3

    Describe it

    Press Ctrl Alt G and type what it did. Enter puts the command in your prompt. Press Tab to see only this folder, this terminal, or commands that failed.

      Questions
      
      
      Before you install
      
    
      
    
      
      
      
        Is loxx free?
        
      Yes. loxx is free and open source under the MIT license. There is no account and no paid plan.
      
      
      
      
      
        Does it send my shell history anywhere?
        
      No. loxx never connects to the internet. The language model is built into the program, so search works the same on a plane. What loxx saves
      
      
      
      
      
        What if I typed a password in a command?
        
      loxx replaces passwords, API keys, tokens and private keys it recognizes with <REDACTED> before saving. For anything unusual, start the command with a space so it is never saved, or run loxx forget --last afterwards.
      
      
      
      
      
        Which systems and shells does it work on?
        
      Linux with bash 4.4 or newer or zsh 5.1 or newer, and macOS 12 or newer with zsh. Windows is not supported. Requirements
      
      
      
      
      
        Why is the download about 80 MB?
        
      The language model and about 29,000 example commands are built into the program, so loxx never downloads anything later and never needs the internet.
      
      
      
      
      
        Will it ever run a command for me?
        
      Never. Choosing a result puts it in your prompt, where you can edit it. You press Enter to run it.
      
      
      
      
      
        Does it slow down my terminal?
        
      Saving runs in the background after each command and adds about 1 to 4 ms. The search list opens in about 30 ms, even with 100,000 saved commands.
      
      
      
      
      
        What if nothing matches?
        
      Commands containing your words come first. Searching by meaning always shows the closest commands, even when none is a good match, so check a result before you run it.
      
      
      
      
      
        How do I delete a command from my history?
        
      loxx forget --last deletes the command you just ran. loxx forget --match TEXT deletes every command containing TEXT, including from the files on disk.
      
      
      
      
      
        How do I remove loxx?
        
      Run loxx uninstall. It puts your shell settings back exactly as they were, asks whether to delete your saved history, and deletes the program.
