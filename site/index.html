      Privacy and architecture
      
    
      Your shell history never leaves your computer
      
    
      Shell history holds server names, file paths and, sometimes, passwords. So loxx keeps all of it on your machine, and has nothing to send anywhere.
      
  
      
  
      
    
      
      
      
      Runs entirely on your machine
      
      
      The search model is built into the one program you install. No account, no API key, no server, and no internet connection, ever. Search works the same on a plane.
      
    
      
    
      
      
      
      A local database, with the vectors inside
      
      
      Commands, their meaning vectors and the keyword index all live in one SQLite file in ~/.local/share/loxx. Only you can read it (permissions 600).
      
    
      
    
      
      
      
      Secrets are removed before saving
      
      
      Passwords, API keys and tokens become <REDACTED> before anything touches the disk. Nothing is ever uploaded, so nothing can leak from a server.

      Configuration
      
      
      Nothing to configure
      
      
      loxx has no config file. Install it and it works: secrets are masked automatically, and your history is imported once. For the rare cases, there are two environment variables and two habits.
      
      
      All settings →
      
    
      
    
      
      
      ~/.zshrc or ~/.bashrc
      

      # Keep the history somewhere else (default: ~/.local/share/loxx)
export LOXX_DB_PATH="$HOME/data/loxx/history.db"

# Don't process new commands in the background
export LOXX_BACKGROUND_EMBED=0

# Never saved: start a command with a space
$  mysql -u admin -pMyRealPassword

# Already saved? Delete it for good
$ loxx forget --last
$ loxx forget --match 'internal.example.com'
