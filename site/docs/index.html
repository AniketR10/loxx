Getting started

loxx saves every command you run in bash or zsh, and lets you find it again by a word in it or by what it did.

1. Install

curl -fsSL https://loxx.run/install | sh

It works on Linux with bash or zsh, and on macOS with zsh. See Download for other ways to install.

2. Open a new terminal

loxx starts saving commands in terminals opened after the install. Terminals that were already open don't have it yet.

Your existing shell history (~/.bash_history, ~/.zsh_history) was loaded during the install, so you can search old commands right away. Imported commands show “imported” instead of a time, because shell history files usually don't record when a command ran.

3. Search

Type loxx and press Enter. Then type what you're looking for:

  • part of the command: port-forward, rsync, a file name
  • or what it did: “undo my last commit”, “restart the web server”, “find big files”

Use ↑ ↓ to choose and Enter to use it. In zsh it appears in your prompt. In bash, press ↑ once to get it. loxx never runs a command for you. More in Searching.

4. Check it's working

loxx status

It shows how many commands are saved, when the last one was, and whether this terminal has the hook. If “this shell” says the hook is not active, open a new terminal. Still stuck? See Troubleshooting.

Something you don't want saved?

Start a command with a space and loxx won't save it. To delete the command you just ran:

loxx forget --last

See Privacy and secrets for what loxx removes on its own.
