Commands

Plain loxx opens the search list. Everything else is loxx <command>. Add -h to any command for its options.

loxx search

Finds commands by meaning and by keyword and prints them. All arguments together form the query.

loxx search [--limit N] <query>

--limit: how many results to print (default 5).

loxx status

Shows the version, where your history is, how many commands are saved, when the last one was, how many secrets were removed, whether every command is ready for search by meaning, and whether each shell has the hook.

loxx forget

Deletes commands and all their runs for good. The text is also wiped from the database files on disk.

loxx forget (--match TEXT | --last) [--yes]
--lastforget the most recently saved command
--match TEXTforget every command containing TEXT (case-sensitive)
--yesdon't ask for confirmation

loxx setup

Adds the hook to ~/.bashrc and ~/.zshrc (each only if that file exists or it is your login shell; on macOS only ~/.zshrc), then loads your existing history once. The installer runs it for you. Safe to run again.

--no-import: don't load existing shell history.

loxx uninstall

Removes the hook from your shell settings, restoring them exactly, asks whether to delete your history, and removes the program if the installer put it there.

--delete-datadelete the history without asking
--keep-datakeep the history without asking

loxx import

Loads existing shell history, with secrets removed just like new commands. With no files given, it loads ~/.bash_history and ~/.zsh_history if they exist. Each file is loaded only once.

--bash FILEbash history file to load
--zsh FILEzsh history file to load
--forceload again even if the file was loaded before

loxx embed

Prepares saved commands for search by meaning. loxx does this in the background after each command, so run it only if loxx status shows commands waiting.

loxx embed --pending

--workers N: commands processed in parallel (default: half your CPU cores).

loxx add

Saves a command by hand. Quote it so it is one argument.

loxx add [--cwd DIR] [--exit CODE] 'command'

loxx version

Prints the version.

Used by the shell hook

You won't need these yourself:

loxx init bash|zshprints the shell code that saves your commands
loxx recordsaves one finished command, in the background
loxx panelopens the search list (the same as plain loxx)
