Troubleshooting and FAQ

Start with loxx status. It shows what's saved, whether the hook is in your shell settings, and whether it's active in this terminal.

Commands aren't being saved

  • Open a new terminal. Terminals opened before the install don't have the hook.
  • If loxx status says the hook isn't in your settings, run loxx setup.
  • bash: the loxx block should be near the end of ~/.bashrc. Tools that change PROMPT_COMMAND after it can switch it off.
  • Commands that start with a space are never saved, on purpose.

Search by meaning doesn't find new commands

New commands are processed in the background shortly after you run them. If loxx status shows commands waiting, run:

loxx embed --pending

loxx: command not found

The terminal you installed from doesn't have loxx yet: open a new terminal, or run exec zsh (or exec bash) in it. The installer puts loxx in ~/.local/bin, and if that folder isn't in your PATH (it usually isn't on a Mac), the hook adds it, so new terminals and the scripts you run from them find loxx. If it's still not found, run ~/.local/bin/loxx setup and open a new terminal.

Ctrl Alt G does nothing

loxx only takes Ctrl Alt G if it still does what your shell does by default. If you've given it another job yourself, loxx leaves it alone: type loxx and press Enter instead. Terminals opened before you installed loxx don't have it yet; open a new one.

On a Mac the key is Ctrl Option G, and the terminal must send Option as Alt. Terminal: Settings → Profiles → Keyboard → “Use Option as Meta key”. iTerm2: Settings → Profiles → Keys → Left Option key → “Esc+”.

Settings

loxx has no settings file. These environment variables cover the rare cases:

VariableWhat it does
LOXX_DB_PATHKeep the history in a different file.
LOXX_QUIET=1Hide “loxx is on” when a terminal opens.
NO_COLOR=1Turn off colors, in the installer too. It's the common switch many tools honour.
LOXX_BACKGROUND_EMBED=0Don't process new commands in the background. Search by meaning then only covers what loxx embed --pending has processed.
XDG_DATA_HOMEIf set, the history goes in $XDG_DATA_HOME/loxx/ instead of ~/.local/share/loxx/.

What loxx changes on your computer

~/.local/bin/loxxThe program.
~/.bashrc, ~/.zshrcOne marked block between # >>> loxx >>> and # <<< loxx <<<. On a Mac, only ~/.zshrc.
~/.local/share/loxx/Your saved commands.
~/.local/state/loxx/A note that the installer put the program there, so uninstall can remove it.

loxx uninstall undoes all of it and puts your shell settings back byte for byte.

FAQ

Does it work on Windows?

Not natively. Windows Subsystem for Linux is Linux, so the Linux install should work there, but it hasn't been tested yet.

Why only zsh on a Mac?

The bash that comes with macOS is version 3.2 from 2007, and loxx needs 4.4 or newer. zsh has been the Mac default since 2019.

What about fish or other shells?

Only bash and zsh for now.

Can I sync my history between computers?

No. Each computer keeps its own history, and loxx never connects to the internet.

Why is it 80 MB?

The search model and the list of about 29,000 common commands are built into the program, so it works offline with nothing to download later.

Can loxx run a command by mistake?

No. Choosing a result only puts it in your prompt. You always press Enter yourself.

Still stuck?

Open an issue with the output of loxx status. It shows counts and paths, not your commands.
