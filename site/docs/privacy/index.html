Privacy and secrets

Your shell history is private, so loxx is built to keep it that way.

Nothing leaves your computer

loxx never uses the internet. Search by meaning uses a language model built into the program, so there's no account, no API key and no cloud service. It works the same on a plane.

What is saved, and where

For each command: the command text, the folder it ran in (and its git repository, if any), the exit code, when it started, how long it took, which terminal session it came from, and the computer's name.

Everything is in one SQLite file, ~/.local/share/loxx/history.db. Only you can read it (permissions 600, folder 700). Nothing is ever sent anywhere.

Secrets are removed before saving

Before a command is written to disk, loxx replaces anything that looks like a secret with a placeholder that names its kind:

mysql -u me -p<REDACTED:password>
export GITHUB_TOKEN=<REDACTED:github-token>
curl -H "Authorization: Bearer <REDACTED:auth-header>"

It recognizes:

  • Known tokens: GitHub, GitLab, AWS, Google, OpenAI, Anthropic, Hugging Face, Slack, Stripe, SendGrid, DigitalOcean, npm and PyPI keys, JWTs, and private key blocks.
  • Secrets by position: passwords in flags like -p and --password, in URLs (user:pass@host), in Authorization, API key and cookie headers, in query strings and JSON, and values of variables named like *_TOKEN, *_SECRET or *_PASSWORD.
  • Strings that look random long enough to be a key, even without a telling name.

The same happens to history loaded from your old ~/.bash_history and ~/.zsh_history. loxx status shows how many secrets were removed.

What loxx can't catch

loxx only removes secrets it recognizes. A short, ordinary password typed as a plain argument may not look like a secret. For those:

  • Start the command with a space. loxx won't save it. Your shell's own history skips it too if it's set to (bash: HISTCONTROL=ignorespace, zsh: setopt HIST_IGNORE_SPACE).
  • Delete it afterwards: loxx forget --last, or loxx forget --match 'part of it'.

The folder name and computer name are saved as they are.

Forgetting is permanent

loxx forget deletes the command, every run of it, and its search data, then wipes the freed space in the database files. A plain database delete would leave the text readable on disk for a while.

Found a secret loxx missed?

Please report it privately, not in a public issue, as described in the security policy. Never send the real secret: describe its shape with an invented one.

This website

loxx.run sets no cookies, has no analytics and loads nothing from other websites: even the fonts are served from here. The Lost commands game keeps today's result in your own browser, and nowhere else.

The site is hosted on GitHub Pages, so GitHub may log your IP address when you visit, as described in GitHub's privacy statement.
