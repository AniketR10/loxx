Download loxx

One command installs loxx for your system. It needs no sudo.

curl -fsSL https://loxx.run/install | sh

Then open a new terminal and type loxx. The installer:

  • downloads the program for your system and checks its SHA-256 checksum,
  • puts it in ~/.local/bin/loxx,
  • adds one marked block to ~/.bashrc and/or ~/.zshrc,
  • loads your existing shell history once.

Prefer to get the installer from GitHub directly? This does the same:

curl -fsSL https://github.com/AniketR10/loxx/releases/latest/download/install.sh | sh

Windows isn't supported. On a Mac, the bash that comes with macOS is too old for loxx.

Download a file yourself

Each file is the whole program: one file, nothing else to install.

SystemFile
Linux, x86-64loxx-linux-amd64
Linux, ARM64loxx-linux-arm64
macOS, Apple chiploxx-darwin-arm64
macOS, Intelloxx-darwin-amd64
Checksumschecksums.txt

Then install it and add the hook to your shell (Linux x86-64 shown):

mkdir -p ~/.local/bin && install -m 755 loxx-linux-amd64 ~/.local/bin/loxx && ~/.local/bin/loxx setup

On a Mac, a file downloaded with a web browser is blocked until you allow it. Download it with curl -fLO instead, or run xattr -d com.apple.quarantine loxx-darwin-arm64 first.

Check a download is genuine

Compare the checksum (use shasum -a 256 -c on a Mac):

grep loxx-linux-amd64 checksums.txt | sha256sum -c

Every file also has a signed record of how GitHub built it. With the GitHub CLI:

gh attestation verify loxx-linux-amd64 --repo AniketR10/loxx

Update

Run the install command again. It replaces the program and keeps your history and settings.

Uninstall

loxx uninstall

This removes the block from your shell settings, leaving them exactly as they were, asks whether to delete your saved history, and deletes the program.

Build from source

You need Go 1.25 or newer, make and curl:

git clone https://github.com/AniketR10/loxx
cd loxx
make build
bin/loxx setup

The first build downloads the search model (about 45 MB) and checks its checksum. go install doesn't work, because the model isn't stored in git.

loxx is free and open source (MIT).
